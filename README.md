
# E-Commerce Sales Analytics & BI Project

## Project Overview
An end-to-end E-Commerce Sales Analytics project using Python, SQL Server and Power BI.

## Technologies Used
- Python
- Pandas
- REST API
- SQL Server
- Power BI
- DAX
- ETL Automation

## Project Features
- Product data extraction through API
- Data cleaning and transformation using Python
- SQL Server data loading and UPSERT
- Automated ETL pipeline
- Synthetic live sales order generation
- Interactive Power BI dashboards
- Customer and product analytics
- Data pipeline monitoring

## Dashboard Pages
1. Executive Overview
2. Customer Analysis
3. Product Analytics
4. Data Pipeline Monitoring

## Project Architecture
API → Python → Data Cleaning → SQL Server → Power BI

## Disclaimer
Sales orders generated by the live order generator are synthetic data for demonstration purposes.
